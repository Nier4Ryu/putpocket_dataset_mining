# GLM 0.8B Dataset Forwarding Evaluation Report

## Executive Summary
One-sample forwarding ran after Docker access was fixed and after overriding the Hugging Face cache to the user-owned cache. A 5-sample subset also ran.

GLM-5.2-0.8B-A0.8B loaded through the current local vLLM 0.25 dtype-auto path and selected the expected Blackwell h192/v128 sparse MLA path. The HF validation prompt produced the expected bee/aviation continuation, but the mined-dataset agent prompts produced incoherent multilingual/token-fragment text and no parseable original Cline XML tool calls.

Result: GLM 0.8B did not solve Query-1 on the tested subset. It is not usable as a correction baseline in the current prompt/tool format because no tested sample reached History-1 verifier, History-2, or judge.

Smallest next action: do not run the full 20-sample evaluation until prompt/tool-call format is changed or a layer-level/prompt-rendering correctness check explains why validation text works but agent prompts produce garbage.
