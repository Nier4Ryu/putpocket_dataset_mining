## Precedence

Architecture resolution uses:

```text
CLI --cuda-arch-list
CLI --cuda-arch-profile
PUTPOCKET_CUDA_ARCH_LIST
PUTPOCKET_CUDA_ARCH_PROFILE
preset default
```

The portable profile resolves to:

```bash
PUTPOCKET_CUDA_ARCH_PROFILE=portable-nvidia
PUTPOCKET_CUDA_ARCH_LIST="8.6 9.0 10.0 12.0"
TORCH_CUDA_ARCH_LIST="8.6 9.0 10.0 12.0"
```

