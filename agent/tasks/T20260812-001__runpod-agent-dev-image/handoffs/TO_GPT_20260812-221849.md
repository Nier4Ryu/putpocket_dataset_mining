## 6. Codex Authentication Policy

Runtime default:

```text
CODEX_HOME=/workspace/.private/codex
```

First trusted Pod login:

```bash
codex login --device-auth
```

Subsequent serialized launches with the same private Network Volume can run:

```bash
codex
```

Expected security policy:

- `auth.json` contains access and refresh tokens.
- Keep `CODEX_HOME` mode `0700`.
- Keep `auth.json` mode `0600` after login.
- Never copy `auth.json` into the image.
- Never commit it, upload it to Docker Hub, print it, or include it in build context.
- Do not share one `auth.json` across concurrently active Pods or machines.
- Optional automation mode must use a RunPod Secret for `OPENAI_API_KEY`, not Dockerfile/template plaintext.

## 10. Docker Hub Publication

BLOCKED: Docker Hub publication did not run.

Reason:

```text
DOCKERHUB_USERNAME unset
PUTPOCKET_RUNPOD_IMAGE_REPO unset
PUTPOCKET_RUNPOD_IMAGE_VERSION unset
Docker Hub username not detected from docker info
```

Human command to unblock:

```bash
export DOCKERHUB_USERNAME=<dockerhub-user>
export PUTPOCKET_RUNPOD_IMAGE_REPO="${DOCKERHUB_USERNAME}/putpocket-runpod-dev"
export PUTPOCKET_RUNPOD_IMAGE_VERSION=cuda12.9.1-ubuntu22.04-agent-v1

```

Then rebuild/tag/push:

```bash

  --platform linux/amd64 \
  --file cloud/runpod/Dockerfile.dev-base \
  --tag "${PUTPOCKET_RUNPOD_IMAGE_REPO}:${PUTPOCKET_RUNPOD_IMAGE_VERSION}" \
  --tag "${PUTPOCKET_RUNPOD_IMAGE_REPO}:git-$(git rev-parse --short HEAD)" \
  --load \

docker push "${PUTPOCKET_RUNPOD_IMAGE_REPO}:${PUTPOCKET_RUNPOD_IMAGE_VERSION}"
```
