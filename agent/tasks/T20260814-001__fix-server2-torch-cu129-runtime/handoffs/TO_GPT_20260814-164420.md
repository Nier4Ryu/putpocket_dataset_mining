# Server-2 vLLM 0.26 CUDA-12.9 Runtime Fix Handoff

## 1. Initial Broken Runtime
REAL_EXECUTION_CONFIRMED: Previous partial rebuild installed torch 2.11.0+cu130 with torch.version.cuda 13.0 on a Server-2 CUDA 12.9 host. vLLM import failed with libcudart.so.12 unavailable and LMCache was not installed.

## 2. Root Cause
CODE_CONFIRMED: The Server-2 lock used the generic PyPI torch 2.11.0 wheel, which resolves to CUDA 13.0 on Python 3.13. LMCache native build then rejected CUDA 12.9 nvcc versus torch CUDA 13.0.

## 3. Exact cu129 Wheel/Source
CODE_CONFIRMED: Official PyTorch cu129 simple index provides `torch-2.11.0+cu129-cp313-cp313-manylinux_2_28_x86_64.whl` at `https://download-r2.pytorch.org/whl/cu129/` with SHA-256 `fde1830d7f79641680865759dc57780e94a9de7e68a82ed61973e9bc7af29423`.
