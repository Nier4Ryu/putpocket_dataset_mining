## Exact score contract

For each selected layer independently, the captured strict-causal matrix is
`A_l[q,k]` for `k < q`. The frozen seed is one on every Q1/Q2 token. The scorer
implements `c_l,1 = u A_l`, `c_l,n+1 = c_l,n A_l`, and cumulative
`s_l,L = sum(c_l,n, n=1..L)`. Every hop and final cumulative token value is
retained per layer, followed only by an exact unnormalized layer sum. Python
IEEE-754 binary64 is used offline. Negative values remain signed; there is no
normalization, clipping, rectification, softmax, or layer multiplication.

## Capture and evidence boundary

The matrix mode records every row in the declared window on every selected
layer and TP rank, chunked as `matrix-rank-XX-chunk-YYYY.jsonl`. It slices the
native pre-top-k/pre-normalization `fp8_fp4_mqa_logits` result to
`[window_start,q)`, excluding self. The loader fails on missing/intermediate or
duplicate rows, noncausal/duplicate keys, token mismatch, post-top-k or
normalized semantics, masked/padding values, TP disagreement, digest failure,
nonfinite data, or source-episode/range mismatch.

The frozen matrix-episode manifest stores the exact prompt tokens/digest,
source frozen-episode path/digest, Q1/Q2 half-open ranges, layer/window/chunk
settings, and benchmark/authorship provenance. SWE-bench Pro supplies the
problem/repository/evaluator; PutPocket authors A1 execution, Q2 freeze, SYS
edit, matrix window, and score. No outcomes are inputs.

Defaults are four layers `[0,22,46,74]`, 256 window tokens, and 32 rows per
chunk. Hard limits are 512 tokens, 523264 edge values per rank, and level 16.
Cost/artifact size are `O(layers * window_tokens^2)`. This is an optional
postprocessor within RunPod Test 2, not a third GPU test.

## Commands and outputs

Run `putpocket-glm52-runpod capture-matrix --dry-run ...`, then the real
`capture-matrix`, followed by `score-matrix` with repeated explicit
`--q1-range`/`--q2-range`, `--window`, `--layers`, and `--max-level`. The
wrapper `scripts/runpod/run_glm52_indexer_matrix_multihop.sh` performs capture,
score, and SHA256SUMS generation.

Outputs are `indexer-multihop-report.json` and
`indexer-multihop-token-scores.jsonl`, plus the raw matrix chunks. The report
binds every matrix artifact, the matrix episode and its source manifest,
recurrence/version, ranges/window/layers, float policy, TP consensus, token-row
schema, and output digest.
