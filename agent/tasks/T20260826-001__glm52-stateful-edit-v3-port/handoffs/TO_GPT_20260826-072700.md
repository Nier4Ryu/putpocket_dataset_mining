# T20260826-001 live GLM DSA score-hook integration fix

## Outcome

Live RunPod query-sum attempt 4 reached real TP4 inference with the exact
`nvidia/GLM-5.2-NVFP4` revision and generated one token, but produced no score
records. The wrapper then failed closed with `CAPTURE_FILES_MISSING`; no
scientific output from that attempt is accepted.

The root cause was an architecture-path mismatch. The package and doctor pin
`GlmMoeDsaForCausalLM`, which subclasses `DeepseekV2ForCausalLM` and runs
`DeepseekV2Model`. The score overlay attested batches only in
`Glm4MoeLiteModel`, so `_batch` remained unset and both score hooks correctly
stayed inert.

This commit regenerates the zero-context score overlay with batch attestation
in `DeepseekV2Model`, retains the GLM-lite hook, and makes enabled capture fail
closed if the model supplies no `input_ids`. The doctor now inspects the actual
DeepSeek/GLM model class for `maybe_set_score_diagnostic_batch`. No inference
decision, selector, cache-reuse mode, or default-OFF boundary changes.
