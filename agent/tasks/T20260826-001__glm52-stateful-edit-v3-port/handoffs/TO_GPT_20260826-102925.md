## Frozen probe and exact execution

The immutable prompt contains 2,105 tokens. Q1 is `[117,2069)`, Q2 is
`[2088,2103)`, so exactly 1,967 content-token rows seed both experiments. The
complete candidate/propagation window is `[0,2103)` and includes the SYS edit
at position 114. System, assistant bridge, and other tokens are candidates but
not seeds. Q1/Q2 ranges and token IDs are identical across experiments.

Experiment 1 retained 15,736 records per TP rank: 1,967 queries times two score
kinds times four layers. Main-attention logits were faithfully reference
recomputed from the same post-RoPE Q/K state as
`scale*((q_nope_192 dot k_nope_192)+(q_rope_64 dot k_rope_64))`, then averaged
over 64 global main-attention heads. Indexer values are native raw
pre-top-k/pre-normalization scores, with 32 TP-replicated indexer heads and the
native `32^-0.5` head aggregation scale.

Experiment 2 retained 264 chunks, 8,412 strict-causal rows/rank, and 8,841,012
edge values/rank. TP consensus max absolute difference was zero. For every
layer independently it computed signed float64
`c_l,1 = u A_l`, `c_l,n+1 = c_l,n A_l`, and
`s_l,L = sum_{n=1..L} c_l,n` through level 6. Every hop and cumulative value
was retained; nothing was clipped, rectified, softmaxed, or normalized, and the
layer aggregate is the exact unnormalized sum, never a product across layers.

## Limitations and next experiment

Main attention is reference-recomputed rather than emitted by the production
sparse kernel; layers are sampled at 0/22/46/74; the window is bounded; the
model is weight-only Marlin on H200; and there is no continuous attempt-7 GPU
telemetry beyond retained run logs and pre/post inventory. Most importantly,
there is no executed A1/tool-action/tool-observation and therefore no stateful
reuse or benchmark-quality claim.

The next experiment should freeze a genuine A1, execute its tool action in a
clean pinned SWE-bench Pro environment, freeze the resulting Q2 observation,
and rerun the recommended equal-position SYS replacement. Then compare normal
full prefill against the true-partial donor-cache path across recompute budgets,
including Q2 decode correctness and evaluator outcome. Given the raw recurrence
instability observed here, do not promote multihop level scores into the online
selector without a separately preregistered scale/normalization design.
