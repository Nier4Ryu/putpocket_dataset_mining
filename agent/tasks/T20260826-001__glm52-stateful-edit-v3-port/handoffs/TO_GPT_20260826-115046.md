## Score origins and analysis

At the exact post-RoPE Q and model-projected K state, the overlay computes a
dense causal reference for every main head:

`scale * ((q_nope dot k_nope) + (q_rope dot k_rope))`.

This is mathematically faithful full-candidate main-attention scoring from the
same model state, explicitly labeled reference-recomputed rather than
kernel-native. It never substitutes sparse post-top-k scores. The native
indexer hook captures `fp8_fp4_mqa_logits` immediately before
`top_k_per_row_prefill`: the learned weighted aggregation across 64 indexer
heads with native quantization scales, `128^-0.5` query/key scale, and
`64^-0.5` head scale.

Every raw record retains causal candidate positions and token IDs. TP-local
main heads concatenate to 64 global heads; the replicated native indexer vector
must agree exactly on all four ranks. Analysis writes the per-rank raw JSONL,
aligned token-score JSONL, and digest-bound JSON report. It reports raw scale
statistics, Pearson, Spearman, independently z-scored cosine, JS divergence
between explicit normalized distributions, and configured top-k overlap,
recall, and NDCG plus aggregate quantiles. Low similarity is a scientific
result, not a test failure: no similarity threshold was preregistered. Strong
positive rank/correlation and cosine, low JS, and high top-k retrieval across
layers/queries would support the distillation-similarity hypothesis; the
opposite consistent pattern would refute it.
