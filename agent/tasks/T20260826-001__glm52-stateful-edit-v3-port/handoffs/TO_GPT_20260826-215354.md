## Exact recurrence

For each selected layer and each valid strictly causal row `q`, sort native raw
pre-top-k/pre-normalization indexer scores `a_l[q,k]`, `k<q`, descending. Exact
ties prefer the lower absolute key position. For rank variant `K`, keep the
first `min(K,q-start)` keys, assign

`w_r = 1 / log2(r + 1)`,

row-normalize the retained weights, and set all other row entries to zero.
Every layer row is independently normalized before the layer transitions are
uniformly averaged, so layer scale and sign cannot dominate. The primary
variant is `rank_dcg_k64`; the sensitivity sweep is K 16/64/256.

The secondary variant population-z-scores every complete valid causal raw row,
applies temperature-1 softmax, independently normalizes each layer, then uses
the same uniform layer average. It is a scale-sensitive nonnegative check, not
the primary metric.

Let `u` be uniform over all and only the 1,967 frozen Q1/Q2 token positions.
With backward-causal row-vector orientation,

- `h_1 = normalize(u T)`;
- `h_{n+1} = normalize(h_n T)`;
- `g_L = (1/L) sum_{n=1..L} h_n`.

Each hop reports its pre-normalization outgoing mass and discarded terminal
mass before normalization. Every reported `h_n` and `g_L` has mass one within
`1e-10`. Hop-only and equal-hop cumulative results are separate everywhere.
Entropy uses natural logs; effective support is `exp(entropy)`. Primary
stability metrics are exact top-k overlap/retention, Jaccard, and NDCG against
the baseline deterministic rank at k 16/64/256. The reported Spearman value is
secondary and is restricted to the explicit union of the two top-k sets.

## Sensitivity conclusion

Level-6 top-64 retention/Jaccard versus level 1, followed by retention versus
level 5, is:

| Transition | Hop vs L1 | Hop vs L5 | Cumulative vs L1 | Cumulative vs L5 |
| --- | ---: | ---: | ---: | ---: |
| DCG K=16 | 0.359/0.219 | 0.938 | 0.531/0.362 | 0.922 |
| DCG K=64 | 0.328/0.196 | 0.969 | 0.500/0.333 | 0.953 |
| DCG K=256 | 0.266/0.153 | 0.984 | 0.359/0.219 | 0.984 |
| z-score softmax T=1 | 0.422/0.267 | 0.953 | 0.562/0.391 | 0.938 |

The robust observation is gradual rank-mass migration away from level 1 while
the next-hop ordering stabilizes strongly at later levels. Equal-hop mixing
retains more of level 1 than hop-only propagation. A wider DCG transition
produces more level-1 drift on this capture; z-score softmax is more
concentrated and retains more level-1 top-64 mass. This is evidence about the
offline propagation design only, not proof of selector quality.
